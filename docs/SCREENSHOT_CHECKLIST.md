# Screenshot/evidence checklist

For a course or portfolio submission, capture final-state screenshots that prove behavior rather than only configuration.

## Classification and routing

- full Flow diagram
- ClassifyRequest Prompt configuration
- RouteRequest expressions and destinations

## Bug path

- bug path configuration
- incomplete bug follow-up response
- successful ticket-creation response with trace
- DynamoDB Explore items table
- detailed DynamoDB ticket item

## Platform and Other paths

- Knowledge Base overview (available)
- data-source sync complete
- KB test showing source chunks
- Flow route `PLATFORM_QUESTION -> FAQKnowledgeBase -> FAQOutput`
- normal FAQ response
- unsupported platform question
- OtherOutput human redirect

## Safety and evaluation

- Guardrail Version 1 ready
- Guardrail attached to ClassifyRequest
- expanded test suite / 10 successful Flow calls
- updated JSONL in S3
- evaluation job completed
- metrics page showing correctness score

## Public GitHub warning

Before publishing screenshots, crop or blur information you do not want public, including account identifiers, usernames, internal resource names, or customer data.
